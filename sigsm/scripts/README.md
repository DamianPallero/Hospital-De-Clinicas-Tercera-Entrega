# Bundles de utilidades SIGSM

Este directorio expone los menús de administración del proyecto desde la aplicación SIGSM.

Uso:

```bash
./sigsm/scripts/run_menu.sh principal
./sigsm/scripts/run_menu.sh usuarios
./sigsm/scripts/run_menu.sh respaldos
./sigsm/scripts/run_menu.sh bd
./sigsm/scripts/run_menu.sh docker
```

Las utilidades reales quedan agrupadas en `Scripts/` por tipo de menú y se invocan desde aquí para mantener la estructura por funcionalidad.
